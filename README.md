## 📱 Project: SMS Spam Classifier

### 🔍 Problem Statement
Classify SMS messages as **Spam** or **Ham (Not Spam)** using Machine Learning techniques.

### 🛠 Techniques Used
- Text preprocessing (tokenization, cleaning)
- Feature extraction (Bag of Words / TF-IDF)
- Naive Bayes classification
- Model evaluation

### 📈 Outcome
- Successfully classified spam messages with high accuracy
- Demonstrated real-world application of probabilistic models

📂 Folder: `SMS_Spam_Classifier/`
